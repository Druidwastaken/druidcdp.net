About:

Glinnem is a free heavy-weight game engine designed for building and running video games.

As of version 1.0, it currently supports 2D and 3D games, and is written entirely in C++17. It's exclusive to Windows, however compiled games created with Glinnem are suitable to run on any OS that supports .exe files.
