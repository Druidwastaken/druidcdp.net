Glinnem Documentation

Version 1.0

Welcome to the official Glinnem documentation.

Glinnem is a free, heavy-weight game engine designed for building and running video games. It supports both 2D and 3D development and is written entirely in C++17.

This documentation covers the installation, editor, development workflow, rendering systems, maps, and other features of Glinnem.

Installation

Glinnem is currently distributed for Windows. Download the latest version and extract it to a location of your choice.

Glinnem version 1.0 is currently intended for Windows development.

Getting Started

After installing Glinnem, launch the editor to create your first project.

Creating a project

Select File > New from the main menu. Glinnem will create the required project structure.

Editor

The Glinnem editor provides tools for creating and managing game content.

The editor is divided into several areas, including the 2D editor, 3D editor, project tools, and configuration settings.

2D Development

Glinnem provides support for developing traditional two-dimensional games.

2D projects can use sprites, textures, objects, and other resources to construct a game world.

3D Development

Glinnem includes a 3D renderer for creating three-dimensional games and environments.

Geometry

3D geometry can be constructed from meshes and other supported geometry types. 

// Example

CreateCube();
CreateSphere();
CreateTriangle();

Scripting

Game logic can be implemented using the systems provided by Glinnem.

This section will contain information about entities, game logic, input, events, and other runtime systems.

Maps

Glinnem uses its own map format for storing game environments and geometry.

Maps created using Shotgun can be loaded by Glinnem during development and runtime.

Exporting

When development is complete, a project can be compiled into a playable game.

Refer to this section for information about distributing games created with Glinnem.

Reference

This section contains technical reference material for Glinnem's systems and APIs.

Project Structure

MyGame/

├── Maps/
