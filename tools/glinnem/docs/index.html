Introduction

Welcome to the official Glinnem documentation.

Glinnem is a free, heavy-weight game engine designed for building and running video games. It supports both 2D and 3D development and is written entirely in C++17.

This documentation contains information about Glinnem's development tools, rendering systems, game systems, file formats, and workflow.

Getting Started

New to Glinnem? Start here.

Install Glinnem, create a project by clicking either 2D project, 3D project, or File > New, and open the editor. From there, you can begin creating your game.

Installation

Glinnem is built for Windows, but is avalible on MacOS and Linux via wine. Download the latest version run the installer, and direct it to a location of your choice.
