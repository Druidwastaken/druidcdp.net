Overview

Glinnem supports 3D editing as well as 2D, in fact it was developed first. This document will give a brief overview on the workflow on the 3D editor.

Shotgun

In order to start building a 3D game, you need to make a map environment first.

There are two ways to start making a map, you can:

  1. Make a new (or open an existing) 3D project in Glinnem, and select "Create map" in the actions panel. (Recomended)
  2. Open Shotgun.exe in your Glinnem bin directory, and follow the prompts.

If you already have a map loaded you can click "Edit map" in the same actions panel, or if you already have a compiled .gmf (Glinnem Map File) you can click "Load map" in the actions panel as well.

Camera

By default, 3D games use a first person camera. in the player entity's properties, you can also set it to third person. When designing Glinnem, I wanted you to have full control over the game, so a camera object can fully bypass this system.

Placing a camera object in your game does not automatically override the player camera, unless you set its "Active" Property. If there happens to be two active camera objects at once, the greater index of the "priority" property will take priority, the player object also has these properties but by default its priority is set to 0.

Cameras can be scripted to have any fuctionality you want. for things like cutscenes, you can adjust the PlayerControl property to set if the player can input movememnt while its active. If you want only certain keys to not be active you can manually adjust that inside the player object itself.
