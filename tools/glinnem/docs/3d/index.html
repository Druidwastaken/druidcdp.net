Overview

Glinnem supports both 3D and 2D game development. The 3D editor was developed first, and provides tools for creating maps, placing entities, setting up cameras, and building the environment for your game.

This documentation provides an overview of the Glinnem workflow and links to more detailed documentation for individual systems.

Shotgun

Shotgun is Glinnem's dedicated 3D map editor. It is used to create and modify maps before they are compiled into a .gmf file, also known as a Glinnem Map File.

To create a new map, make or open a 3D project in Glinnem and select Create Map in the Actions panel. This is the recommended method.

Glinnem will create the required map files and allow you to open the map in Shotgun.

Alternatively, you can open Shotgun.exe from the Glinnem bin directory and follow the prompts.

If a map is already loaded, select Edit Map from the same Actions panel to open it in Shotgun.

If you already have a compiled .gmf file, select Load Map to load it into Glinnem.

Camera

By default, 3D games use the player's camera as their primary camera. The Player entity can be configured to use a third-person camera instead of the default first-person view.

A separate Camera object can be used when you need to control the camera independently from the player.

A Camera object only overrides the player's camera when Active is enabled.

If multiple cameras are active at the same time, the camera with the highest Priority is used. The Player camera has a default priority of 0.

Cameras can also be scripted for things such as cutscenes. The PlayerControl setting determines whether the player can move while a scripted camera is active.

Individual player movement keys can also be changed through the Player object.
