Introduction to Shotgun

In order to start building a 3D game, you need to make a map environment first.

There are two ways to start making a map, you can:

  1. Make a new (or open an existing) 3D project in Glinnem, and select "Create map" in the actions panel. (Recomended)
  2. Open Shotgun.exe in your Glinnem bin directory, and follow the prompts.

If you already have a map loaded you can click "Edit map" in the same actions panel, or if you already have a compiled .gmf (Glinnem Map File) you can click "Load map" in the actions panel as well.

Commands

When launching Shotgun from Glinnem's bin directory, you get access to the command prompt before the main window opens, where you can either enter your project directory, or run commands that Shotgun will refer to after the main window opens.
Commands and their fuctions are listed below:

Command Usage Function
--pref Prompts you a couple of times to enter your preferences manually. Loads your saved preferences.
--prefdir [Directory] Enter the directory to your preferences.txt Loads your saved preferences.
--debug [Bool] Replace the first parameter with either true or false. Turns debug mode on or off.

Usage

When you're in the editor, there is a simple toolbar at the top left of the screen. From there, you can insert primative geometry, such as cubes, spheres, polygon-prisms, cylinders, flat triangles you can edit the verticies of, flat quadrillaterals you can edit the verticies of, and one more button to insert a .obj file as raw triangles or as one big object.

To swap between modes, you can press M to switch to the move tool, C to switch to the scale tool, and R to switch to the rotation tool

The Editor

The Glinnem editor provides the tools used to construct and configure a game.

Documentation for the individual editor systems can be found in the relevant sections of the navigation menu.
